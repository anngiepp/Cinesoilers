# CineSoilerS

Frontend desarrollado con React + Vite + TypeScript inspirado en una experiencia visual cinematográfica.

---

# Tecnologías utilizadas

* React
* Vite
* TypeScript
* CSS3
* Node.js
* Visual Studio Code

---

# Desarrollo del proyecto

## Paso 1 — Verificar instalación de Node.js y npm

Antes de iniciar el proyecto se verificó que Node.js y npm estuvieran correctamente instalados.

### Comandos utilizados

```bash id="q8m31"
node -v
npm -v
```

### Evidencia

![Paso 1](./src/images/1.png)

---

## Paso 2 — Crear el proyecto React con Vite

Se creó el proyecto utilizando Vite + React + TypeScript.

### Comando utilizado

```bash id="u5d90"
npm create vite@latest
```

### Configuración seleccionada

```txt id="j3x88"
Project name: cinesoilers
Framework: React
Variant: TypeScript
```

### Evidencia

![Paso 2](./src/images/2.png)

---

## Paso 3 — Ejecutar el proyecto

Después de instalar las dependencias se ejecutó el servidor de desarrollo.

### Instalación de dependencias

```bash id="z7n14"
npm install
```

### Ejecutar proyecto

```bash id="k9v20"
npm run dev
```

### Evidencia

![Paso 3](./src/images/3.png)
